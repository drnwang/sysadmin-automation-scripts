# Help Desk Labs

Hands-on tutorials for help desk and desktop support skills, built on the [`lab.local` server lab](../windows/server-lab/).

| Lab | What you build | Time |
|---|---|---|
| [Ticketing system (osTicket)](./ticketing-osticket/) | A service desk with help topics, SLAs, departments, canned responses, and 20 mock tickets to work | 4–6 h |
| [Knowledge base](./knowledge-base/) | 10 tested KB articles and SOPs: lockouts, MFA, VPN, drives, printers, Outlook, slow PCs, phishing, onboarding, offboarding | 2 evenings |
| [PowerShell toolbox](./powershell-toolbox/) | A GUI tool for unlocks, resets, finding a user's computer, remote health checks, and print queues | 1–2 weekends |
| [Asset inventory](./asset-inventory/) | Snipe-IT with AD sync, device lifecycle, licenses, and a Lansweeper network scan to reconcile against | 3–4 h |

Suggested order: **ticketing → knowledge base → asset inventory → toolbox**. The ticket queue gives you real reasons to write KB articles and use the other tools.
