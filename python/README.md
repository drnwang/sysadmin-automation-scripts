# Python Scripts

## System info: `system_info.py`

Prints basic information about the machine it runs on: operating system and release, CPU architecture, and number of CPU cores. Works on Windows, macOS, and Linux.

```bash
python3 system_info.py
```

Example output:

```
System Info:
OS: Linux 5.15.0
Architecture: x86_64
CPU Count: 4
```
