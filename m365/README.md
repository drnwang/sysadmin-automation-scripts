# Microsoft 365 Labs

Hands-on tutorials for the cloud side of the job: Microsoft 365 administration, device management with Intune and Autopilot, and hybrid identity that connects the on-premises `lab.local` domain to the cloud.

All three use **one Microsoft 365 Business Premium trial tenant** (about one month), so do them back to back.

| Order | Folder | What you build |
|---|---|---|
| 1 | [`m365-admin/`](./m365-admin/) | Tenant setup, users and licenses, groups and shared mailboxes, Teams/SharePoint sharing, least-privilege roles, MFA with Conditional Access |
| 2 | [`intune-autopilot/`](./intune-autopilot/) | Autopilot registration, compliance and BitLocker policies, update rings, Win32 apps, compliant-device Conditional Access |
| 3 | [`hybrid-identity/`](./hybrid-identity/) | Entra Connect Sync with password hash sync, OU filtering, group-based licensing, password writeback and self-service reset |

> **Status:** tutorials ready. Results and screenshots to be added after each lab is run.
